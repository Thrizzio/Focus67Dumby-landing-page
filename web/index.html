The engineering under the sticky note

Four small inventions that make local accountability feel human.

No black-box productivity score. The app composes tiny, inspectable signals into a nudge you can understand, tune, and turn off.

01

👁️ Hybrid vision + window title pipeline

gemma4:e2b or qwen3-vl:2b reads a 512×288 in-memory screenshot alongside the Win32 foreground window title. A 16:9 perceptual pixel-diff cache skips static screens below the <3% threshold, so a still editor costs zero extra GPU cycles.

512×288 frame + Win32 title → local verdict
  • Screenshot never written to disk
  • Static frame diff cache <3%
  • Deterministic fallback if Ollama is asleep
02

⏱️ 30-second workspace calibration

The first 30 seconds automatically whitelist every window you open—IDE, terminal, docs, localhost—for instant 0ms multi-window switching. Add popups with [+ Trust Window] and keep a rolling four-window breadcrumb trail for OAuth logins and handoffs.

03

🚨 Continuous escalating interference

Choose Gentle Toast, Toast + Sound, or Popup Takeover + Sound. On strikes 2, 4, 6… the sticky note forces itself frontmost, flashes red, and shakes—just enough to interrupt the spiral, never enough to hijack your machine.
